# 7tube product requirements snapshot

## Product goals

- Deliver a smooth, addictive, TikTok-style feed experience.
- Help advertisers target highly relevant audiences without sacrificing creator trust.
- Keep the system modular so teams can ship web, mobile, creator, and monetization features independently.

## MVP capabilities

- Vertical feed with autoplay-ready cards.
- Creator metadata, tags, and category-based ranking signals.
- Ads matching engine that scores campaigns using category, tags, audience segments, retention, and budget.
- Health and preview API endpoints for integration and QA.

## Future capabilities

- Login, following graph, comments, likes, saves.
- Video upload and transcoding workflows.
- Content moderation, copyright review, and trust/safety operations.
- Multi-region delivery, experimentation, recommendations, and subscriptions.
