# 7tube Roadmap

## Phase 1
- Establish monorepo foundations.
- Prototype feed ranking and ad matching.
- Ship a browsable feed UI and API mocks.

## Phase 2
- Add authentication and creator onboarding.
- Persist events and monetization data.
- Support campaign budget pacing and reporting.

## Phase 3
- Introduce moderation tooling.
- Run ranking experiments.
- Expand analytics for creators and advertisers.
